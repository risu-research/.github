# RISU Research

RISU Research publishes open technical work on machine-readable semantics, interoperability, and agent/API infrastructure.

## Public work

- [Appeal Discovery Consumer](https://github.com/risu-research/appeal-discovery-consumer) — A provider-independent reference consumer for the experimental `appeal` semantic across supported carriers.

- [HTTP→MCP Method-Inference Soundness Profile](https://github.com/risu-research/http-mcp-method-inference-soundness-profile) — An experimental executable profile for evaluating soundness in HTTP-method-derived MCP ToolAnnotations.

Our public artifacts emphasize explicit scope, reproducibility, and clear claim boundaries.
